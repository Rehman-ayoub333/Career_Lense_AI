# Research Evaluation — Final

No results are claimed or fabricated anywhere in this document. It specifies how results will be produced and judged once the dataset (`RESEARCH_DATASET_SPEC.md`) exists and the pipeline (`AI_PIPELINE_FINAL.md`) is implemented.

## Metrics, each justified against a specific research question
| Metric | Answers | Formula | Why this metric and not another |
|---|---|---|---|
| Faithfulness rate | RQ1 | `verified claims that are also gold-`matched`` / `all claims marked verified` | Direct measure of "when the system says verified, is it actually right" |
| Hallucination rate | RQ1 | `hallucination_candidate: true count` / `total claims with non-null evidence_quote` | Direct, mechanically-computed measure of the exact failure mode this thesis targets — no human judgment needed to compute it, only to validate the gold set it's checked against |
| Claim-level precision/recall/F1 | RQ1 | Standard IR formulas, `verified`/`matched` treated as positive class, against `gold_status` | Standard, comparable to the baselines (§below), the metric a reviewer will expect and can sanity-check independently |
| Evidence-extraction accuracy | RQ1 | Fraction of `evidence_quote`s (when non-null and gold-matched) whose span overlaps the `gold_evidence_span` above a set threshold | Distinguishes "found the right requirement" from "found the right *sentence*" — a finer-grained check than status accuracy alone |
| Unsupported-claim rate | RQ1 | `claims with status: matched but verification: unresolved` / `all matched claims` | The ungrounded baseline's failure mode made visible — this is the number that doesn't exist at all in the current shipped pipeline, and is the headline comparison |
| Score variance under identity perturbation | RQ2 | Standard deviation of `score` across name/institution variants of the same base item | Directly reuses the perturbation methodology cited in `CAREERLENS_MASTER_RESEARCH_AUDIT.md` §4/§9 |
| Human agreement (inter-annotator κ) | Validates the gold set itself | Cohen's κ, per `RESEARCH_DATASET_SPEC.md` | Without this, F1-against-gold is meaningless — a low-κ gold set can't support a precision claim |
| Latency / token cost | Practical framing only, not a research claim | From `lib/logger.ts`'s existing recorded token counts, averaged per run | Cheap to report, answers "what does grounding cost," a fair question any reviewer will ask |
**Explicitly not used:** ranking metrics (recall@k) — there's no ranked list, CareerLens matches one CV against one opportunity, not a corpus (research audit §11, restated here as binding, not just noted). User-satisfaction surveys are not a primary metric — too noisy to anchor RQ1/RQ2 alone; may appear as a secondary, clearly-labeled qualitative addendum if time permits.

## Baseline
**Primary baseline: the current (pre-this-plan) CareerLens pipeline, ungrounded** — i.e., Stage 1's `claims[]` output with `verification` always treated as absent/unknown (equivalent to trusting `status` at face value with no Stage 2 check at all). This is the correct baseline because it's literally "what shipped before this thesis's intervention," making the comparison a clean before/after rather than a comparison against an unrelated system. **Secondary baselines, for context, not as the primary comparison:** keyword/token overlap (what the named commercial competitors effectively do) and embedding cosine similarity (the "smarter than keywords, no grounding" middle point, and the same technique the cited bias literature used, letting Experiment 2's methodology be independently sanity-checked against a known technique). **Not used:** a from-scratch trained classifier (data-hungry, out of scope) or a full RAG system (answers a different question, per `AI_PIPELINE_FINAL.md`'s explicit non-goal).

## Experiments (full protocol)

### Experiment 1 — Evidence grounding (RQ1/H1)
**Objective:** measure whether grounding improves faithfulness/reduces hallucination vs. the ungrounded baseline. **Dataset:** the held-out test split (`RESEARCH_DATASET_SPEC.md`). **Independent variable:** grounded vs. ungrounded pipeline (a boolean flag into `grounding.ts`, or equivalently, whether its output is consulted at all). **Dependent variables:** the metrics table above. **Baselines:** as above, reported alongside for context. **Procedure:** run both conditions on every test item (multiple independent runs per item at `temperature: 0`, averaged, per the non-determinism note); compute metrics; run the significance test appropriate to each metric's type (proportion test for rates, standard F1 reporting with confidence intervals given the small n). **Expected interpretation:** a significant faithfulness gain and hallucination-rate reduction supports H1; report effect size alongside significance given the modest sample. **Threats to validity:** small/synthetic dataset, single labeler primary pass (mitigated by the inter-rater subsample), single model.

### Experiment 2 — Bias sensitivity (RQ2/H2)
**Objective:** measure whether grounding reduces identity-driven score variance. **Dataset:** a perturbation subset — each base item rendered in K (recommended K=6–10: at least two names per relevant demographic axis crossed with at least two institution-prestige tiers, following the cited Brookings/NAACL methodology's shape at a scale appropriate to this project's budget) variants with all substantive content held fixed. **Independent variable:** grounded vs. ungrounded pipeline. **Dependent variable:** per-item score standard deviation across its variants. **Procedure:** run both pipelines across all variants; compare the two conditions' variance distributions (Levene's test, or a paired per-item comparison if the sample supports it). **Expected interpretation:** per `RESEARCH_CONTRIBUTION_FINAL.md` — genuinely open. **Critical confound check:** report faithfulness (Experiment 1's metrics) on this same perturbation subset alongside variance, specifically to rule out "grounding reduced variance by making outputs generically more conservative/repetitive" rather than more accurate — a variance reduction with a faithfulness *drop* on the same items would not support H2 as a real finding, and this document requires both numbers be reported together, never variance alone.

### Experiment 3 — Ablation
**Objective:** confirm the intervention is real and separable, and identify which piece of it matters. **Conditions:** (a) full grounded system, (b) without Stage 2 verification (claims shown as if `verification` were always `verified`, i.e. the literal ungrounded baseline — this condition is shared with Experiment 1, not duplicated work), (c) without the nonce-delimited injection defence, run only against the adversarial-input fixture set (`TESTING_STRATEGY_FINAL.md`), isolating the security claim's measured effect rather than leaving it asserted-only, (d) without schema-constrained decoding (free-form JSON, same prompt) — isolates how much of the reliability story is the schema vs. the wording. **Only these four conditions** — no ablation of personalization, confidence calibration, or an ontology, since none of those exist in this system to remove (research audit §13, restated).

## Statistical methodology
Binomial/bootstrap confidence intervals for rate metrics at this sample size; two-proportion z-test or Fisher's exact test (whichever is appropriate given the smallest expected cell count) for the faithfulness/hallucination-rate comparison; Levene's test for Experiment 2's variance comparison. No method more elaborate than this is justified by a 60–150-item dataset — reaching for one would be a methodological overreach, not rigor.

## Error analysis
For every claim scored `hallucination_candidate: true`, a human review pass (the student, ideally blind to which pipeline produced it) categorizes the cause: genuine model fabrication, a paraphrase too distant for the 0.85 threshold (a detector false-positive, not a model failure), or a labeling error in the gold set itself. This breakdown is required in the thesis's Results/Discussion chapters (`CAREERLENS_MASTER_RESEARCH_AUDIT.md` §17) — a raw hallucination-rate number without this breakdown would overstate what's actually been shown.
